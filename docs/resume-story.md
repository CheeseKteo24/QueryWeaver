# Resume and interview story (draft)

Do not paste these bullets into a resume until the corresponding benchmark is implemented and measured.

- Built a verifiable enterprise data copilot that routes natural-language questions across hybrid document retrieval and guarded Text-to-SQL, returning source-level evidence for every answer.
- Designed an offline evaluation harness covering retrieval relevance, SQL execution accuracy, groundedness, latency, and cost; enforced quality thresholds in CI to prevent regressions.
- Instrumented multi-step agent workflows with distributed traces and operational dashboards, enabling tool-level failure analysis and p95 latency/cost optimization.

## Interview structure

Use a four-part narrative: user problem → architecture decision → measured trade-off → failure and iteration. Avoid listing framework names without explaining why they were chosen.
